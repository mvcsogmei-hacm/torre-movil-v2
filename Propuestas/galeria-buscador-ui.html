3 · Tarjeta de proyecto

Cómo se ve cada proyecto en los resultados. (Cada una con dos ejemplos: avance medio y avance alto.)

① Fila compacta menos scroll

Filas finas tipo lista: entran muchos más por pantalla. Ideal para listas largas.

② Tarjeta limpia

Mucho aire, poco color, jerarquía tipográfica. El % y el PIM abajo, con barra fina.

③ Panel de datos

Medidor de ejecución + estado + PIM, estilo tablero. La más informativa de un vistazo.

Decime tu combinación (ej.: 1.1 + A + ②) y ensamblo el buscador final.
